# Reparto de Punto · Sala de Despecho

Calculadora de cierre para meseros: captura la venta de cada mesero y calcula el punto (9.5% de la venta) y lo que le toca a cada área.

| Área | % de la venta |
|---|---|
| Gerencia | 4.3% |
| Barra | 1.7% |
| CAJA | 1.5% |
| Cocina | 1.1% |
| Host | 0.9% |
| **Punto total** | **9.5%** |

## Usarla en el iPhone

1. Abre la app en Safari: https://kalleros.github.io/calleros/
2. Toca **Compartir** (cuadro con flecha) → **Agregar a inicio**.

Los datos que captures se guardan solo en tu teléfono.
